Comparative Evaluation of CFAR and Deep Learning-Based Ship Detection in High-Resolution SAR Imagery

CA-CFAR / OS-CFAR Baselines vs YOLO11n Detection

Project Overview

This project presents an automatic ship detection system for Synthetic Aperture Radar (SAR) images. The system evaluates two traditional CFAR-based detection methods, CA-CFAR and OS-CFAR, alongside a YOLO11n deep learning object detector. The primary objective is to compare conventional signal-processing approaches with deep learning for ship detection in high-resolution SAR imagery.

Objective

To develop an automated SAR ship detection pipeline that evaluates CA-CFAR and OS-CFAR traditional detection baselines alongside YOLO11n deep learning detection, and compares their detection performance using a common evaluation framework.

Preprocessing

For visualization, the uploaded SAR image is display-enhanced using intensity normalization and contrast enhancement to improve visual interpretation. These operations are visualization-only and are not fed to the evaluated CFAR or YOLO11n detectors.

CA-CFAR / OS-CFAR Baselines

CA-CFAR (Cell-Averaging CFAR) and OS-CFAR (Ordered Statistics CFAR) are used as traditional signal-processing baselines. Both methods estimate local background statistics from training cells surrounding a guard region and apply adaptive thresholds to identify potential ship targets. OS-CFAR uses an ordered-statistics approach to estimate the background level and is evaluated alongside CA-CFAR under the same dataset and IoU-based evaluation framework.

YOLO11n Deep Learning Detector

A trained YOLO11n object detection model is used to identify ship targets and generate bounding boxes together with confidence scores. On the HRSID held-out test set of 1,962 images containing 5,922 ship instances, the Ultralytics evaluation reported Precision 0.902, Recall 0.797, mAP@0.5 0.894, and mAP@0.5:0.95 0.640. Under the common evaluation at confidence 0.40, YOLO11n achieved Precision 0.891, Recall 0.804, and F1-score 0.846.
